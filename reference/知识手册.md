# 累计 HTML 知识手册

## 先提议，再生成

在一个专题收敛或多个案例形成可复用方法时，主动说明建议纳入的主题与价值，询问是否生成或更新。用户明确同意后才修改知识源并运行生成脚本。历史同意只覆盖当时范围，不自动授权后续所有专题。用户暂缓时，在学习计划记下本次主题，等有新增知识或用户要求后再提。

制作手册不能替代当前解题或成长验证，也不自动创建网站、托管或定时任务。

## 专题内容

每个专题保留：问题背景、关键判断、第一性原理中影响结论的推导、解题步骤、适用边界、案例与反例、可复用模板、常见误用、下一步和来源。内容由当前讨论与核验资料整理，不把全部聊天堆进网页。

个人能力状态、同事评价和敏感内部细节默认不进入手册。内部来源可使用经用户确认的脱敏名称和定位，不生成外网链接或上传内容。来源不足的归纳明确说明局限。

## 数据与生成

在用户数据目录维护 `knowledge/handbook.json`。按 [handbook.json](../templates/handbook.json) 的书级结构填写，专题字段见下方。修改已有专题前先读原内容，以稳定 id 更新，不丢弃其他专题。

每个 topic 必需字段：

- `id`：稳定的英文小写短横线 ID。
- `title`、`updated_on`：标题与实际更新日期（YYYY-MM-DD）。
- `problem`、`context`、`judgment`：问题、条件和当前判断。
- `steps`、`boundaries`：非空字符串列表。
- `case`、`template`：具体案例与可复用模板；模拟案例明确标记。
- `sources`：来源列表。每条含 title、checked_on；公开来源带 http/https 的 url，内部或当前对话来源用 locator 说明出处，scope 说明适用范围。无外部来源时使用当前讨论的真实定位，不能虚构文章。
- 可选：`tags` 字符串列表、`first_principles` 对象（goal/facts/constraints/mechanism/options/validation 各为字符串）、`counterexample`、`pitfalls` 字符串列表、`next_action`。

确认内容范围后生成：

```sh
python3 <skill-dir>/scripts/build_handbook.py --input <data-dir>/knowledge/handbook.json --output <data-dir>/handbook.html
```

更新已有 HTML 时加 `--replace`；脚本会保存上一个版本。知识 JSON 修改前同样保留原文件，修正事实时保留来源和更新时间。脚本只处理用户已经确认的内容，运行命令不能代替获取同意。

## 显示与验收

使用 [handbook.html](../assets/handbook.html) 内联模板。单文件、无外部依赖，具备专题目录、全文搜索、无结果提示与打印样式。来源链接可外连，但离线阅读和搜索不依赖网络。

交付前实际打开生成的 HTML，检查正文、目录跳转、搜索与清空、打印全部专题、窄屏排版，以及无脚本错误和外部资源请求。没有浏览器或渲染工具时，说明未完成视觉验证，不能声称已检查布局。

只展示最终完整手册，提供真实绝对路径链接。示例和测试产物留在隔离目录，不作为用户个人知识手册交付。
