# A/B 实验

## 解决什么问题

很多变化无法靠前后对比判断因果，因为季节、渠道、运营活动同时在变。A/B 实验把用户随机分组，只让一个因素不同，从而估计改动的因果效果，也让团队用证据而不是职位来决定方案。

## 核心步骤

1. **写假设**："因为<洞察>，我们认为<改动>会让<人群>的<指标>发生<方向>的变化，机制是<原因>。"
2. **定指标**：一个主要指标（或综合评价指标 OEC），若干护栏指标（体验、性能、收入、投诉），以及用于解释的诊断指标。
3. **定随机单元和人群**：按用户、设备、会话、账户还是区域随机；存在网络效应或双边市场时，考虑分区实验或时间片轮换。
4. **估样本量和时长**：根据基线、最小可检测效应、显著性水平和统计功效计算；时长至少覆盖一个完整的使用周期（如一整周）。
5. **上线前检查**：分流是否均匀、埋点是否正确，必要时先跑 A/A 测试。
6. **运行中**：按预定计划运行，避免频繁查看后提前停止；监控样本比例偏差（SRM）和护栏指标。
7. **分析**：看效应大小和置信区间，而不只是 p 值；检查新奇效应和分群差异；多指标、多组对比时控制误报。
8. **决策与沉淀**：全量、迭代或放弃，把结论和学习写进实验记录。

## 适用条件

- **适合**：流量足够、结果能在合理时间内观察、可以随机分组的改动。
- **前提**：有可靠的分流和埋点能力（见[埋点与数据需求](tracking-plan.md)），以及事先写好的假设和指标。
- **换用或简化**：流量小、效果周期长、涉及公平或法规限制、双边网络效应强时，改用准实验、灰度对比或定性研究；明显缺陷修复和战略性决策，实验只是依据之一。

## 误用与反例

- 一显著就停 → 按预定样本量和时长运行完。
- 只看主要指标上涨 → 同时看护栏和分群，避免伤害长期或某类用户。
- 分流不均仍下结论 → 先排查 SRM。
- 把"不显著"当成"没效果" → 可能是样本不足，看置信区间。
- 什么都做实验 → 按决策的价值和可逆性决定是否值得实验。

## 行业变形

- [教育](../industries/education.md)：效果周期长、受学期影响，同班学生互相影响，常按班级或学校随机，并关注教学公平。
- [内容/社区/社交](../industries/content-community.md)：用户之间互相影响，用分区、按社交圈或时间片实验，推荐策略要看长期效应。
- [本地生活/出行/O2O](../industries/local-services.md)：供需互相影响，用户级实验会干扰对照组，用城市或区域分区实验。
- [企业服务 SaaS](../industries/saas.md)：按账户计样本常常不足，多用灰度和设计伙伴客户反馈。
- [医疗健康](../industries/healthcare.md)、[金融科技](../industries/fintech.md)：涉及诊疗、授信或定价的实验需要伦理与合规审查。
- [广告与商业化](../industries/ads-monetization.md)：广告主预算和竞价在实验组间互相干扰，用长期保留组观察用户效应。
- [出海与全球化](../industries/globalization.md)：按市场分别实验，各市场的季节、节假日和用户构成不同，结论不直接跨市场推广。
- [开发者与工具类产品](../industries/developer-tools.md)：账户和项目样本少，同一团队的成员互相影响，按账户随机，多用分批发布和前后对比。

## 不同阶段怎么用

- **newcomer 新人**：照着用。和数据同学一起完成一次实验，从假设写到结论，重点理解护栏和 SRM。
- **independent_pm 独立 PM**：会选会改。独立设计实验、判断样本和时长、正确解读结果并做决策。
- **senior 资深**：判断何时不该用实验，处理网络效应和长期效应，对实验结论提出挑战。
- **expert 专家**：建立本领域的实验规范、指标体系和实验知识库。
- **lead 负责人**：推动用证据决策的文化，同时防止团队只做容易测量的小优化。
