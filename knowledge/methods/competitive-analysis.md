# 竞品与市场分析

## 解决什么问题

竞品分析常变成功能对比表，却回答不了"我们该怎么做"。有用的竞品分析从用户任务出发，识别用户真正的替代选择，理解对手的定位、模式和能力来源，进而找到差异化机会和需要防守的地方，并明确自己的定位。

## 核心步骤

1. **定分析目的**：要回答什么决策问题：定位、功能取舍、定价、是否进入新市场。目的决定分析深度和对象。
2. **界定竞争范围**：从用户的[待办任务](jtbd.md)出发，列直接竞品、间接替代（用不同形态解决同一任务）和非消费（手工处理或干脆不做）。
3. **收集信息**：亲自注册、使用、付费体验；用户评价、更新日志、招聘信息、财报和公开发言；销售和客户反馈。每条标注来源和日期。
4. **按维度比较**：目标用户、核心价值主张、商业模式与定价、关键体验、渠道、能力与资源来源，而不只是功能有无。
5. **看结构与趋势**：用五力模型看行业结构；留意从低端或新市场切入的颠覆路径。
6. **形成定位**：我们的目标客户是谁、他们的替代方案是什么、我们的独特价值及证据、为什么是现在。
7. **输出决策建议**：做什么、不跟什么、持续监测哪些信号。

## 适用条件

- **适合**：立项、定位调整、竞争压力下的功能取舍、进入新市场。
- **前提**：分析目的清楚；能亲自体验主要竞品。
- **换用或简化**：日常竞品跟踪简化为固定的信号清单；需要大规模系统对比时可委派 [competitor-analyst](../../reference/agents.md)。

## 误用与反例

- 比功能表上打勾的数量 → 从用户任务和价值主张比较。
- 只盯直接竞品 → 补上间接替代和非消费。
- 竞品有什么就跟什么 → 判断它对我们目标用户的价值、与我们的定位是否一致。
- 把二手信息当事实 → 标注来源和日期，关键结论亲自验证。

## 行业变形

- [企业服务 SaaS](../industries/saas.md)：竞争主要发生在销售环节，赢单和丢单复盘是最有价值的一手材料。
- [电商与零售](../industries/ecommerce.md)：价格、供给和履约能力常比功能更关键。
- [游戏](../industries/gaming.md)：同品类的玩法、美术、运营节奏和玩家口碑是主要比较维度。
- [AI 产品](../industries/ai-product.md)：底层模型能力快速趋同，差异化看数据、场景和工作流整合。
- [中后台与内部系统](../industries/internal-platform.md)：竞品是外采系统和业务自建工具，比较要包含切换成本和维护成本。

## 不同阶段怎么用

- **newcomer 新人**：照着用。亲自体验两三个竞品，按导师给的维度写对比并标注来源。
- **independent_pm 独立 PM**：会选会改。界定竞争范围，从分析中得出明确的取舍建议。
- **senior 资深**：判断竞争动态对战略的影响，识别何时应该选择不跟。
- **expert 专家**：持续跟踪领域格局和技术趋势，为团队提供判断框架。
- **lead 负责人**：用竞争分析支撑定位和资源投入，建立团队的市场信号机制。
