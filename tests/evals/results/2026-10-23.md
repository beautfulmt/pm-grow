# pm-grow v2.1.1 验收记录

日期：2026-10-23。宿主：Claude Code（VS Code 扩展）；执行者为宿主的 general-purpose 子代理，沿用宿主模型 claude-opus-5-5。全部检查只使用临时目录和模拟材料，未接触真实个人档案。

## 本版改动

记录时机由“在自然停顿处”改为每轮回复结束前对照记录清单检查，命中就写。改动涉及 SKILL.md §7、reference/evidence-and-records.md、reference/reasoning.md 的标准档和 templates/growth-log.md：

- 记录清单新增“出现了新问题”；
- 不记录的情况新增“同一问题上没有新变化的追问轮次”；
- stale-problem-prompt 的首轮预期新增一条：为新问题写 exploration 记录并登记回访，读回后才说已记录。

起因见 [v2.1.0 验收记录](2026-10-22.md)里的“待定”一项：第一轮结束、导师在等用户回答时，两次演练一次写了记录、一次没写，原规则两种都允许。导师无法知道哪一轮是最后一轮，用户不再回来时，没写的那次就不会留下这个新问题，之后既不会回访，也不会进入报告。早记的内容后来有变化，再写一条记录更新或更正即可。
