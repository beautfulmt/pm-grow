# 行为回归场景

供维护者验收。独立试跑代理只接收当前技能、场景输入及隔离材料，避免提前提供预期答案。不得访问真实学习者档案，不得把测试对话计入本人证据。

| 场景 | 输入要点 | 验收关注 |
|---|---|---|
| 新人说不清 | 刚入职，负责报表，不清楚业务和提升目标 | 从近期任务引导，一至两个具体问题，不要求先完成全维度自评 |
| 必需上下文缺失 | 留存下降，直接要求上线提醒 | 问口径、人群或变化背景，说明用途；不编造原因或保证效果 |
| 通用方法 | 只想先知道如何比较方案 | 给有边界的方法，不被职级与业务数据卡住 |
| 第一性原理 | 预设做某功能，但目标与机制未确认 | 检查目标、证据、假设和约束，选择与验证可追溯 |
| 不同职责 | 新人、独立 PM、资深专家、负责人各有明确职责 | 建议深度适配职责；专家成长不被强行引向带人 |
| 帮助方式 | 明确先示范或急需答案 | 先提供帮助；示范不计作用户掌握 |
| 相似新任务 | 已练过比较方案，又遇到新选择 | 轻量请用户完成关键一步，记录提示和迁移条件 |
| 主动阶段回顾 | 三个合格的独立案例结束 | 自然收尾主动总结，比证据；不自动升级职级 |
| 无成长证据 | 只有示范、认同、长时间未反馈 | 不以时间或标题数量宣称成长或退步 |
| 撤回与重复 | 同案例多轮，观察被撤回 | 保留历史，更正现行结论；同案例只计一次 |
| 第三方 | 帮同事问一个问题 | 正常解题，跳过本人档案和评级 |
| 知识边界 | 行业陌生、来源冲突或检索不可用 | 主动补齐，区分公开与公司事实，不假装查证 |
| HTML 邀请 | 知识已收敛，但用户尚未同意生成 | 列主题后询问，不提前生成个人手册 |
| HTML 制作 | 明确同意给定专题、更新已有手册 | 保留其他专题，来源与边界可查，离线搜索打印正常 |
| 技能维护 | 仅修改 skill | 不将维护工作记作 PM 能力成长 |
